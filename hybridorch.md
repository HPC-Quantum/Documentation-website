# Hybrid Orchestration (Quantum–HPC)

This section introduces system-level concepts for **orchestrating hybrid Quantum–HPC workflows**, including scheduling, batching, synchronization, and resource coordination.

The goal is to help readers reason about *where time is spent*, *where resources stall*, and *how execution patterns interact* in Quantum-Centric Supercomputing (QCSC) workflows—before diving into concrete implementations.

The section is structured in two parts:

- **Workflow Scenarios**: a set of static, step-by-step walkthroughs that illustrate common hybrid execution patterns and their dominant bottlenecks.
- **Workflow Explorer (work in progress)**: an interactive visualization tool that allows users to explore these patterns dynamically and experiment with parameter changes.

For the theoretical background and a discussion of recurring bottlenecks in hybrid Quantum–HPC systems, see the accompanying Medium article:  
[Hybrid Quantum–HPC Systems: Bottlenecks, Tradeoffs, and Practical Solutions](https://medium.com/@claudia.friedsam/hybrid-quantum-hpc-systems-bottlenecks-tradeoffs-and-practical-solutions-1faa3e21db23)
